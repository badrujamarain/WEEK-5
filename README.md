# Week 5: Node.js, Express and MongoDB Lab

A web development learning project using Node.js, Express,
MongoDB and Mongoose. It includes routing examples, HTML forms,
student-data examples and database operations for person records.

## Technologies Used

- JavaScript
- Node.js
- Express
- MongoDB
- Mongoose
- HTML

## Features

- Basic Express routes and URL parameters
- A student information form
- Processing form submissions and returning JSON responses
- A form for adding person records
- Creating and listing person records in MongoDB
- Additional database helper examples for filtering,
  counting, updating and deleting records

## Project Files

- `index.js` — Express application and routes
- `Week4lab.js` — Mongoose model and database helpers
- `StudentInfo.html` — Student information form
- `Personform.html` — Person information form
- `Student.json` — Sample student data
